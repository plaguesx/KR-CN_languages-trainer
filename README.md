# 🔢 Числа 中文 · 한국어

Тренажёр китайских и корейских числительных: https://plaguesx.github.io/KR-CN_languages-trainer/

- 📖 **Учить** — карточки с чтением и озвучкой, большие числа (万/만, 亿/억), конвертер любого числа
- 🎯 **Викторина** — 10 вопросов, рекорды, повтор ошибок
- ⏰ **Время** — как называть время по-корейски и по-китайски, часы со стрелками
- 📦 **Где?** — слова места: на, под, перед, за, рядом, слева, справа, внутри, снаружи, между
- 🕵️ **Чей это?** — китайский / сино-корейский / родной корейский
- 🧩 **Пары** — соедини число и слово на время
